# Wind-aware coverage path planning

Research software for joint grid orientation, strip routing, and per-leg speed optimization for multirotor coverage missions under steady wind.

## Related paper

Yanchao Liu and Tao Wu. **Energy-Optimal Coverage Path Planning for Multirotors under Wind: Joint Grid Orientation, Strip Routing, and Speed Optimization.** Accepted for publication in *Drone Systems and Applications*.

Please cite this paper when using the software or results. Publication volume, pages, and DOI will be added when available. See `CITATION.cff` for citation metadata.

The manuscript-associated software snapshot is [v1.0.0](https://github.com/profyliu/wind-aware-coverage-planning/releases/tag/v1.0.0). This repository includes software, example inputs, and supporting result files. It does not distribute the manuscript, LaTeX sources, or review materials. The `paper/data/` directory name is retained because the experiment scripts use that relative path; it contains research data only.

## Installation

Use Python 3.10 or newer. From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run the planner

```bash
python code/gcs_plugin/planner.py code/scenarios/Farmland.kml \
  --wind-dir 45 --wind-speed 3 --altitude 80 \
  --camera sony_a6000_16mm \
  --overlap-side 0.70 --overlap-front 0.80 \
  --output-kml flight_path.kml --output-wp flight_path.waypoints
```

The planner exports a KML route and a MAVLink waypoint file for Mission Planner/QGroundControl. Wind direction is the meteorological FROM bearing, clockwise from north. Per-leg speed optimization is enabled by default. `--ground-speed` sets the nominal/fallback speed; use `--no-optimize-speed` for fixed-speed operation. See `python code/gcs_plugin/planner.py --help` for camera, speed-bound, transition-speed, and trigger options.

## Files and experiments

- `code/decomposition.py`: selective grid decomposition.
- `code/routing.py`: strip sequencing, orientation search, and speed optimization.
- `code/gcs_plugin/`: KML parsing, camera geometry, coordinate conversion, and mission export.
- `code/scenarios/`: synthetic scenario definitions and KML examples.
- `code/experiments.py`, `code/instance_gen.py`: benchmark runner and polygon generators.
- `code/minlp_validation.py`: exact Held–Karp dynamic-programming comparison; no commercial optimizer is required.
- `code/sensitivity_analysis.py`: power-model and wind sensitivity analysis.
- `code/sitl_validation/`: PX4 software-in-the-loop scripts.
- `paper/data/`: available CSV results, summaries, and exported mission files.

Run from the repository root; experiment commands can overwrite the corresponding supplied results:

```bash
python code/generate_paths.py --scenario 01
python code/generate_paths.py --scenario convex_meadow
python code/generate_paths.py --scenario high_concave_terrain
python code/generate_paths.py --scenario corridor_channel
python code/generate_paths.py --scenario 01 --wind-sweep
python code/phi_sweep.py
python code/farmland_kml.py
python code/fig_farmland_paths.py
python code/minlp_validation.py
```

Use each script's `--help` where provided for experiment options. Figures generated by the scripts are written to `paper/figures/`; experiment results are written to `paper/data/`. The superseded `results_full_backup_pre_optphi.csv` is omitted.

## PX4 validation

PX4 SITL requires a separate PX4 installation and its simulator/build dependencies. Install the Python log/MAVLink dependencies with `python -m pip install -r requirements-sitl.txt`. The scripts preserve the original experimental configuration, including author-machine PX4 paths: configure those paths for your installation before running. The plotting script accepts an explicit ULog path. Raw PX4 ULog files are not included; the available repository data do not include every raw simulation artifact.

The software and available results are released as the manuscript-associated snapshot. Full benchmark experiments and PX4 simulations have not been rerun for repository publication.
